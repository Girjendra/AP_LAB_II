## 🚀 How to Run

**1. Clone the repository**

```bash
git clone https://github.com/Girjendra/AP_LAB_II.git
```

**2. Navigate to the required lab folder**

```bash
cd AP_LAB_II/LE1
```

**3. Compile the Java program**

```bash
javac FileName.java
```

**4. Run the program**

```bash
java FileName
```

Replace `FileName` with the name of the Java class containing the `main()` method.
